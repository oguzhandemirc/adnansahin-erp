## Komutlar

```bash
cd patron/sunucu
npx prisma migrate deploy && npx prisma generate && npx tsx scripts/db-rolleri.ts   # migrate dev/reset YASAK
npx tsx scripts/tesis.ts tesis-ac --ad="Adnan Şahin" [--tesis=<uuid>] [--saklama=13|3|25|tumu]   # kimlik verilmezse üretilir; tek tesis
npx tsx scripts/tesis.ts durum                                       # tesis + kurulum kayıtları (sırsız)
npx tsx scripts/tesis.ts kurulum-kaydet --kurulum=<uuid> --acik-anahtar=<x> [--pasif]   # fabrikanın patron-bulut-anahtar.ts çıktısı
npx tsx scripts/tesis.ts kullanici-kilitle --kullanici=<ad> --gerekce="…" [--talep=<no>]   # acil bulut kilidi; açık oturumlar kapanır
npx tsx scripts/tesis.ts kullanici-ac --kullanici=<ad> [--gerekce="…"]   # bulut kilidi + kaba kuvvet kilidi kalkar
npx tsx scripts/tesis.ts dogrulama-kapat --kullanici=<ad> --gerekce="…" [--talep=<no>]   # TOTP kapanır; TEK kurtarma yolu, ad basılmaz
npx tsx scripts/tesis.ts kullanici-yeniden-iste [--gerekce="…"]   # damga sıfır: sonraki fabrika gönderimine dek yeni giriş 503
npm run typecheck:scripts && npm run lint        # commit kapısı altıncı proje olarak aynısını ölçer (tip + eslint + lint-baseline.json tavanı)
node ../../scripts/agir-is.mjs -- npx tsx scripts/run-all-tests.ts [ad-parçası]   # yalnız *_test DB
```

`.env` (repoya girmez, 0600): `GOC_DATABASE_URL` · `DATABASE_URL` (uygulama rolü) · `ESITLEME_DATABASE_URL` (eşitleme rolü) — üçü AYNI `_test` DB'yi, ÜÇ AYRI rolle gösterir (`tekserp_fabrika_*` ASLA) · `ANAHTAR_DIZINI` · `PORT` (varsayılan 4620); isteğe bağlılar `.env.example`te. Bekçiler `scripts/test_*.ts`; harita `Teks-Erp/docs/BEKCI-HARITASI.md` § patron-bulutu. CI'da ayrı "Patron sunucusu" job'ı (PG 16, `migrate deploy`, roller, lint + tavan + tip + kapı kapsamı + bekçi koşucusu).

### Tek DB — roller (tam metin)

- **Tek veritabanı** (`DATABASE_URL`ın veritabanı): kiracı tabloları (`tesis_id` + RLS ENABLE + FORCE + `tesis_yalitimi`) ile yönlendirme tablosu (`installation_routes`; `db-grants.ts` `ROUTING_TABLES`) AYNI DB'dedir. Bağlantı nesnesi `lib/tesis-db.ts` (`TesisDbRouter` adı çağrı yerleri değişmesin diye korunur; içi tek `Database`).
- **Göç rolü** (`GOC_DATABASE_URL`, tablo sahibi): `prisma migrate deploy` + `scripts/db-rolleri.ts` + tesis CLI'si (`scripts/tesis.ts`, denetim aktörü `satici-cli`). Sunucu bu rolle BAĞLANMAZ.
- **Uygulama** (`DATABASE_URL`) ve **eşitleme** (`ESITLEME_DATABASE_URL`) rolleri: LOGIN NOSUPERUSER NOBYPASSRLS, tablo sahibi değil; ad + parola URL'den okunur, `db-rolleri.ts` kurar/hizalar (parola çıktıya yazılmaz).
