# Alan kural dosyaları

Kök `CLAUDE.md` her oturumda yüklenir ve yalnız çekirdek değişmezleri taşır; bir alana dokunmadan önce buradaki dosya okunur. Yeni karar notu arşive (`docs/history/CLAUDE-NOT-ARSIVI.md`) yazılır, ilgili dosyaya tek kural satırı eklenir.

| Alan | Dosya |
|---|---|
| Defter · ters kayıt · hard delete · numaralandırma · mükerrer · sebep katalogları | `defter.md` |
| Sevkiyat · çuval · brüt · storno/iade · parti · yarı mamul | `sevkiyat.md` |
| Fason · kartela | `fason.md` |
| İş emri · sipariş bağı · rota · renk · kalite | `is-emri.md` |
| KK1 · idempotency · kurşun planlama | `kk1.md` |
| Tambur · finalize · kesim · top düzeltme · refakat kartı | `tambur.md` |
| Belge · etiket · şablon | `belge-etiket.md` |
| Raporlar · filtre · liste · arama | `raporlar.md` |
| Yetki · izin · rol · süperadmin · modül bayrakları | `yetki-izin.md` |
| Sürüm · yayın · kurulum · migration | `surum-yayin.md` |
| Genel · uzak erişim · keşif · cihaz · donanım | `genel.md` |
| Patron bulutu · eşitleme · imza · kapatma düğmesi | `patron-bulutu.md` |

Eski (2026-09) sürümler — `dokuma.md` ve `finans.md` dahil, bu fabrikada kapsam dışı olanlar — gerekçe ve ölçüm hikâyesiyle birlikte `docs/history/kurallar-2026-09/` dizinindedir; yalnız başvuru içindir.
